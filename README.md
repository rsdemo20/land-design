# land-design

Настольный 3D-планировщик участка для эскизной расстановки построек, инженерных объектов и растений. Приложение позволяет задать основу участка, создавать несколько вариантов дизайна и сравнивать их. Это инструмент для предварительного планирования, а не замена геодезическому или строительному проекту.

## Возможности

- Режим «Создание участка» для границ и постоянного окружения и режим «Дизайн» для отдельных вариантов расстановки.
- Размещение и редактирование типовых объектов и геометрических примитивов: положение, поворот, размеры и цвета.
- Защита объектов от случайного изменения, координатная сетка и управление 3D-камерой.
- Локальное хранение схемы в JSON с проверкой данных и атомарной записью.

## Стек и запуск

Python 3.10, Ursina 7.0.0 (Panda3D устанавливается как её зависимость). Основная целевая среда — Windows и PowerShell.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main_3d.py
```

Также можно запустить `run_3DLand.ps1` или `run_3DLand.bat`: скрипты создают локальное окружение и устанавливают зависимости при необходимости.

Тесты ядра выполняются без запуска 3D-окна:

```powershell
python -m unittest discover -s tests
```
